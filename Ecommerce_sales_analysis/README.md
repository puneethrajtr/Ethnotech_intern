# 📊 E-Commerce Customer Insights Dashboard

## 🚀 Project Overview

This project is a **data analytics dashboard** built using **Python, Pandas, and Matplotlib** to analyze e-commerce data.
It helps in understanding **revenue trends, customer behavior, and product performance** through visualizations.

---

## 🎯 Objectives

* Analyze **monthly revenue trends**
* Identify **top-selling products**
* Understand **customer purchasing behavior**
* Analyze **city-wise and category-wise revenue**
* Visualize data using **Matplotlib charts**

---

## 🛠️ Tech Stack

* **Python**
* **Pandas** – Data manipulation
* **Matplotlib** – Data visualization

---

## ▶️ How to Run the Project

```

```

