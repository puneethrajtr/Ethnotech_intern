# 🌦️ Weather App

## 📌 Project Overview

The **Weather App** is a simple web application that allows users to check **real-time weather information** for any city worldwide.

It fetches live weather data using an external API and displays key details like temperature, humidity, and wind speed in a clean and user-friendly interface. ([GitHub][1])

---

## 🚀 Features

* 🌍 Search weather by city name
* 🌡️ Real-time temperature display
* 💧 Humidity information
* 🌬️ Wind speed details
* ☁️ Weather condition (clear, cloudy, etc.)
* 🎯 Simple and responsive UI

---

## 🛠️ Tech Stack

* **HTML** – Structure of the web page
* **CSS** – Styling and UI design
* **JavaScript** – Logic and API handling
* **RapidAPI (Weather API)** – Fetch real-time weather data ([GitHub][1])

## ⚙️ How It Works

1. User enters a **city name**
2. JavaScript sends a request to the **Weather API**
3. API returns weather data
4. Data is displayed on the UI
